# Registro de decisões técnicas

Este diretório registra decisões que afetam arquitetura, manutenção, distribuição ou experiência do usuário.

Cada decisão deverá documentar contexto, opções consideradas, decisão, consequências e estado (proposta, aceita ou substituída).

As decisões iniciais estão descritas em `../ARCHITECTURE.md`. Decisões específicas serão registradas conforme o protótipo responder às questões em aberto.
